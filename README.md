## 退款和取消：全文最需要认真读的一节

先把条款原话放在这：RackNerd 服务条款（最后修订于 2026 年 7 月）写明“付款后默认不退款”，退款仅按个案酌情处理，需要开工单沟通。没有 30 天无理由退款，也没有任何形式的无理由退款保证——第三方监测确认其全部 49 个套餐均为无退款。

围绕这个默认规则，有几条具体机制决定了你的钱什么时候会“蒸发”：

1. **取消要提前通知**。VPS、共享主机这类常规服务，需要在续费日前至少 5 天通过客户区提交取消请求；独立服务器等合同制服务要 7 天，还可能有提前终止费。逾期没取消会自动扣下一周期费用，而且按默认不退款规则追不回。有经验的用户的做法是设一个续费日前 7 天的日历提醒，留出缓冲。
2. **逾期有滞纳金**。账单逾期 3 天后可能加收 10% 滞纳金；多数服务到期后 7 天自动终止，独立服务器最快 3 天就释放硬件。
3. **取消后数据立即删除**。服务终止后数据即刻永久删除，没有宽限期，也没有恢复工单。提交取消前务必备份。
4. **账户余额不可退**。充值进账户但没消费的钱，同样不退。

实况比条款稍微有弹性：第三方 cancellation policy 拆解文章提到，刚付款、几乎没使用、一两天内就开工单说明情况，有协商空间；用到周期中段不想用了，基本只能等周期结束自然取消。文章里还举过一个真实场景——有人冲动买了 $11/年 的套餐，两周后想退，结果发现钱基本要不回来。用最小成本的套餐试水，是应对“无退款”最实际的办法。
